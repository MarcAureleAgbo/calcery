# Archives de pilotage

Les fichiers contenus dans `audits/` et `plans/` sont des photographies historiques datées. Ils sont conservés sans réécriture et ne représentent pas automatiquement l'état courant du produit, du déploiement, de Search Console ou de Cloudflare.

L'[audit complet du 21 septembre 2026](audits/AUDIT_COMPLET_CALCERY_2026-09-21.md) est la source du [plan d'action du 21 septembre 2026](plans/PLAN_ACTION_CALCERY_2026-09-21.md). Le plan ne constitue pas une autorisation d'exécution.

Pour la documentation active :

- l'état opérationnel courant se trouve dans [`docs/STATUS.md`](../STATUS.md) ;
- les décisions durables se trouvent dans [`docs/DECISIONS.md`](../DECISIONS.md).
